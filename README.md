# MCZhang-s-BBCModsHack-Plugin

基于 __BepInEx__，为（几乎）所有的BBC模组创建的通用作弊菜单。

__我不保证全部功能都能正常在所有版本正常运行！


（这个仓库的模组在开发时几乎全部使用了DeepSeek，如果你介意的话，请不要使用）


---

## 安装方法

1. 下载 [`BepInEx`](https://github.com/BepInEx/BepInEx/releases)。
2. 将 `BepInEx` 解压到游戏根目录。
3. 打开 `BepInEx` 文件夹并创建 `plugins` 文件夹。
4. 下载 `BaldisBasicsClassicModsHack.dll`。
5. 将 `BaldisBasicsClassicModsHack.dll` 放入 `BepInEx/plugins/` 文件夹。
6. 启动游戏，按 `Tab` 关闭或开启菜单。
